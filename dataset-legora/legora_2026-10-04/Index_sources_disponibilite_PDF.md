# Index des sources et disponibilité des PDF — Jurisprudence comparée sur la requalification des travailleurs de plateformes

Ce dossier contient :
- `decisions.json` : les 48 décisions structurées selon le format demandé.
- Le présent index, qui précise, pour chaque décision, si le texte intégral a été lu dans le corpus de recherche juridique interne de Legora (et peut donc être cité avec précision) ou s'il s'agit d'une référence identifiée mais non disponible en texte intégral dans ce corpus (dans ce cas, aucun PDF ne peut être généré depuis cet environnement, qui n'a pas d'accès internet).

**Important** : l'environnement de travail ne permet pas de télécharger des PDF depuis des bases externes (Légifrance, CENDOJ, BAILII, Westlaw, EDJT/TST, etc.). Pour les décisions listées comme "disponibles dans le corpus interne", le texte a été lu via l'outil de recherche juridique mais n'est pas exporté ici sous forme de fichier PDF autonome (il reste consultable dans l'environnement Legora). Pour les décisions "non disponibles", il faudra les récupérer depuis la base officielle mentionnée.
